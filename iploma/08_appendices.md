# ՀԱՎԵԼՎԱԾՆԵՐ

## Հավելված Ա. Հիմնական տվյալային ֆայլերը

olist_valid_transactions.parquet — մաքրված գործարքային տվյալներ։

customer_classification_dataset.parquet և classification_dataset.csv — դասակարգման դիտարկումներ, հատկանիշներ և թիրախ։

classification_metrics.csv — դասակարգման փորձերի գնահատման չափանիշներ։

test_predictions.csv — test հատվածի կանխատեսումներ։

customer_segments.parquet և segment_profiles.csv — վերջին snapshot-ի սեգմենտների արդյունքներ և պրոֆիլներ։

kmeans_comparison.csv — K-Means տարբերակների համեմատություն։

best_classification_model.pkl — պահպանված դասակարգման մոդել։

final_kmeans_model.pkl և clustering_scaler.pkl — կլաստերացման մոդել և մասշտաբավորման օբյեկտ։

## Հավելված Բ. Հիմնական հասկացությունների բառարան

| Հասկացություն | Բացատրություն |
| --- | --- |
| Snapshot | Հաշվարկային պահ, որի դրությամբ նկարագրվում է հաճախորդի վիճակը |
| Recency | Վերջին գնումից անցած ժամանակը |
| Frequency | Դիտարկման պատուհանում պատվերների քանակը |
| Monetary | Դիտարկման պատուհանում գնումների արժեքների գումարը |
| K-Means | Կլաստերացման ալգորիթմ, որը դիտարկումները բաժանում է k խմբի |
| Silhouette | Կլաստերների համախմբվածությունն ու տարանջատումը գնահատող չափանիշ |
| Davies–Bouldin | Կլաստերների ցրվածությունն ու փոխադարձ մոտիկությունը գնահատող չափանիշ |
| Average Precision | Precision-Recall կորի վրա հիմնված դասակարգման չափանիշ |
| Data leakage | Ապագա տեղեկության ներթափանցում մուտքային հատկանիշների մեջ |
| MLflow | Մեքենայական ուսուցման փորձերի և մոդելների կառավարման գործիք |

## Հավելված Գ. Վերջնական հանձնումից առաջ լրացվող քայլերը

Ստուգել ժամանակային բաժանման սահմանները՝ համոզվելով, որ թիրախային 30-օրյա պատուհանները չեն հատվում։

Իրականացնել K-Means կայունության գնահատում մի քանի սկզբնարժեքով և հաշվարկել ARI։

Վերջնականացնել կլաստերների քանակի ընտրությունը՝ համադրելով բոլոր չափանիշները։

Կատարել դասակարգման շեմի ուսումնասիրություն validation տվյալների վրա և ամրագրել շեմը test-ից առաջ։

Լրացնել MLflow փորձերի գրանցումը տվյալների տարբերակով, ամսաթվերով, պարամետրերով և չափանիշներով։

Կառուցել խմբաքանակային կանխատեսման հոսք և Power BI հաշվետվություն, եթե պահանջվում է վերջնական հանձնումով։

Ավելացնել notebook-ների հղումները, գրադարանների տարբերակները և կոդի գործարկման հրահանգները։
