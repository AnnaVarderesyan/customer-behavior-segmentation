# Հաճախորդների վարքագծային տվյալների հիման վրա սեգմենտավորման և դասակարգման համակարգի մշակում

## Նախագծի նկարագրություն

Այս նախագծի նպատակն է մշակել հաճախորդների վարքագծային տվյալների հիման վրա սեգմենտավորման և դասակարգման համակարգ։

Աշխատանքի ընթացքում ուսումնասիրվում են հաճախորդների գնումների պատմությունը, հաշվարկվում են վարքագծային ցուցանիշներ, իրականացվում է հաճախորդների սեգմենտավորում և կառուցվում է մեքենայական ուսուցման դասակարգման մոդել՝ ապագա գնումների հավանականությունը գնահատելու համար։

## Տվյալների աղբյուր

Նախագծում օգտագործվում է **Olist Brazilian E-Commerce Public Dataset** տվյալների բազան, որը պարունակում է բրազիլական էլեկտրոնային առևտրի պատվերների և հաճախորդների վերաբերյալ տվյալներ։

Տվյալների հիմնական աղյուսակներն են՝
- Orders
- Customers
- Order Items
- Products
- Payments
- Reviews
- Sellers

## Իրականացվող աշխատանքներ

1. Տվյալների ներբեռնում և ուսումնասիրություն։
2. Տվյալների մաքրում և նախապատրաստում։
3. Հաճախորդների վարքագծային ցուցանիշների հաշվարկ։
4. RFM վերլուծություն։
5. Հաճախորդների սեգմենտավորում K-Means ալգորիթմով։
6. Ապագա գնումների հավանականության դասակարգման մոդելի մշակում։
7. Մոդելների գնահատում և համեմատություն։
8. Արդյունքների վերլուծություն և ներկայացում։
